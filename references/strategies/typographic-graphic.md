# Typographic and Graphic

Use this family when type, verified numbers, and graphic fields should become the main spatial masses.

## Kernels

- `diagonal-zine`: oversized type and an asymmetric diagonal route.
- `kinetic-type-islands`: several typographic masses with objects nested beside them.
- `number-led-scoreboard`: verified numeric anchors with attached detail trails.
- `stamp-label-field`: one hero label surrounded by controlled tags and stamps.

## Failure controls

- Do not distort exact copy into illegible word art.
- Numeric emphasis does not authorize ranking, scoring, or a winner.
- Never invent badges, seals, certification marks, or endorsement stamps.
- If the renderer cannot reproduce required copy reliably, escalate it to deterministic overlays.
