# Flow and Path

Use this family when a visible route should carry several indivisible semantic nodes. The path is the layout engine, not decoration placed behind an unchanged grid.

## Kernels

- `serpentine-flow`: one curved spine with alternating nodes. It is one ordinary option, never the default answer for portrait comparisons.
- `spiral-unfold`: progressive scale or density around a clear core.
- `zigzag-ribbon`: angular switchbacks with a node at each major turn.
- `river-confluence`: several grouped tributaries converging on a conclusion.

## Failure controls

- Reject a route that becomes two columns with a line drawn between them.
- Do not use branching or convergence to invent causality, categories, or ranking.
- Keep every product, value, qualifier, and label inside its declared content group.
- Pair the kernel with one routed visual system; do not copy the sample image's palette or texture by default.
