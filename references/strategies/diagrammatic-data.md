# Diagrammatic and Data

Use this family when verified relationships, categories, or sequences can become the primary composition.

## Kernels

- `subway-map`: a few transit lines and source-supported transfer nodes.
- `decision-tree`: an explicit root question with verified branches.
- `annotated-blueprint`: a central object or system with numbered callouts.
- `spectrum-map`: nodes placed on a verified or explicitly non-ranking continuum.

## Failure controls

- Never invent causality, specifications, dimensions, ordering, or recommendations.
- If the source has no real relationship graph, choose a neutral comparison route instead.
- Connectors must resolve cleanly and remain traceable at output size.
- Decorative technical marks must be visually distinct from factual annotations.
